# मोहनलाल पुनिया — बिलिंग ऐप

एक छोटा वेब-ऐप जो दो तरह के बिल बनाता है (टोटल बिल और एस्टीमेट), सबको सर्वर पर सेव रखता है, और किसी भी डिवाइस (फ़ोन/लैपटॉप) से खोलने-एडिट करने देता है। GitHub Pages पर मुफ़्त में लाइव किया जा सकता है।

## इसमें क्या है

| File | काम |
|---|---|
| `index.html` + `dashboard.js` | डैशबोर्ड — सभी सेव किए बिल दिखाता है, खोजें/फ़िल्टर करें, खोलें/कॉपी/डिलीट करें |
| `bill-total.html` + `bill-total.js` | टोटल बिल (आपका मौजूदा पूरा बिल — SQ.foot/QTY/RATE) |
| `bill-estimate.html` + `bill-estimate.js` | एस्टीमेट (सिर्फ़ Details/Rate/Amount — वही ऑटो-कैलकुलेशन लॉजिक) |
| `style.css` | दोनों बिल टाइप + डैशबोर्ड की स्टाइल |
| `app-common.js` | Firebase से जोड़ने और बिल सेव/लोड करने का कॉमन कोड |
| `firebase-config.js` | **इसमें आपको अपनी Firebase जानकारी भरनी है** (नीचे स्टेप्स) |

## स्टेप 1 — Firebase सेट करें (मुफ़्त, ~3 मिनट)

क्रॉस-डिवाइस सेव/एडिट के लिए एक फ्री क्लाउड डेटाबेस चाहिए — GitHub Pages सिर्फ़ फ़ाइलें दिखाता है, डेटा सेव नहीं करता।

1. https://console.firebase.google.com खोलें → **Add project** → कोई भी नाम दें → Google Analytics बंद रख सकते हैं → **Create project**.
2. प्रोजेक्ट खुलने पर, होम स्क्रीन पर **`</>`** (Web) आइकन पर क्लिक करें → कोई निकनेम दें → **Register app**.
   Firebase अब आपको एक `firebaseConfig = { apiKey: "...", ... }` जैसा ऑब्जेक्ट दिखाएगा।
3. उन 6 वैल्यू को कॉपी करके `firebase-config.js` फ़ाइल में पेस्ट करें (placeholders की जगह)।
4. बाईं तरफ़ के मेनू में **Build → Firestore Database → Create database** पर क्लिक करें।
   - कोई भी नज़दीकी location चुनें।
   - अभी के लिए **Start in test mode** चुनें (इससे ऐप बिना लॉगिन के डेटा पढ़/लिख सकता है)।

> ⚠️ **टेस्ट मोड 30 दिन बाद अपने-आप बंद हो जाता है और लिखना/पढ़ना रुक जाएगा।**
> इसे स्थायी और थोड़ा सुरक्षित बनाने के लिए, Firestore के "Rules" टैब में जाकर यह डालें और Publish करें:
> ```
> rules_version = '2';
> service cloud.firestore {
>   match /databases/{database}/documents {
>     match /bills/{billId} {
>       allow read, write: if true;
>     }
>   }
> }
> ```
> ध्यान रहे — इस सेटिंग से कोई भी व्यक्ति जिसे आपकी वेबसाइट का लिंक पता है, डेटा पढ़/लिख सकता है (कोई लॉगिन नहीं है)। एक निजी बिज़नेस टूल के लिए यह आमतौर पर ठीक है, लेकिन अगर आप चाहें तो असली यूज़र-लॉगिन (Firebase Authentication) बाद में जोड़ा जा सकता है — पूछ लीजिए।

## स्टेप 2 — GitHub Pages पर लाइव करें (मुफ़्त)

1. https://github.com पर अकाउंट बनाएं (अगर नहीं है)।
2. नया **repository** बनाएं (उदाहरण नाम: `mohanlal-billing`) — Public रखें।
3. इस फ़ोल्डर की सभी फ़ाइलें (`index.html`, `style.css`, सभी `.js` फ़ाइलें) उस repository में अपलोड करें
   (GitHub की वेबसाइट पर "Add file → Upload files" से भी हो जाता है, कमांड लाइन ज़रूरी नहीं)।
4. Repository की **Settings → Pages** में जाएँ → "Branch" में `main` चुनें → Save।
5. एक मिनट बाद ऊपर एक लिंक दिखेगा जैसे:
   `https://yourusername.github.io/mohanlal-billing/`
   यही आपकी लाइव वेबसाइट है — फ़ोन हो या लैपटॉप, यह लिंक खोलने पर वही डैशबोर्ड और वही बिल दिखेंगे।

## नए फ़ीचर

- **डार्क/लाइट थीम** — ऊपर दाईं तरफ़ 🌙/☀️ बटन से थीम बदलें। यह पसंद हर डिवाइस पर अलग-अलग याद रहती है (सिर्फ़ उस ब्राउज़र में)। ध्यान दें: बिल का असली पेज (जो प्रिंट/PDF होता है) हमेशा सफ़ेद-काला ही रहता है, चाहे थीम कुछ भी हो — सिर्फ़ आस-पास का ऐप डिज़ाइन बदलता है।
- **शेयर करें (PDF)** — बिल एडिटर में "शेयर करें" बटन दबाने पर फ़ोन का नेटिव शेयर मेनू खुलता है, जहाँ से PDF सीधे WhatsApp, Bluetooth, Email वगैरह से भेजा जा सकता है। यह सुविधा सिर्फ़ फ़ोन/टैबलेट ब्राउज़र में और सिर्फ़ HTTPS वेबसाइट पर काम करती है — GitHub Pages अपने-आप HTTPS देता है, इसलिए लाइव साइट पर यह ठीक चलेगा। कंप्यूटर पर या इस सुविधा के सपोर्ट न होने पर यह अपने-आप "Save as PDF" इस्तेमाल करने को कहेगा।

## इस्तेमाल कैसे करें

- डैशबोर्ड (`index.html`) से **"+ नया टोटल बिल"** या **"+ नया एस्टीमेट"** पर क्लिक करें।
- बिल भरें, फिर ऊपर **"सेव करें"** दबाएँ — यह अब सर्वर पर सेव हो गया और डैशबोर्ड में दिखने लगेगा।
- डैशबोर्ड से किसी भी बिल पर **"खोलें / एडिट"** दबाकर उसे दोबारा खोल-बदल सकते हैं (किसी भी डिवाइस से)।
- **"कॉपी"** उसी बिल का डुप्लीकेट बनाकर नया एडिटेबल बिल खोल देता है (बिल नं. के आगे "-COPY" लग जाता है, इसे बदल लें)।
- **"हटाएं"** बिल को हमेशा के लिए मिटा देता है — सोच-समझकर इस्तेमाल करें।
- **Save as PDF** और **प्रिंट करें** पहले जैसे ही काम करते हैं।

## नोट

- अगर `firebase-config.js` में जानकारी नहीं भरी है, तो डैशबोर्ड में लाल मैसेज दिखेगा — बिल फिर भी टाइप/प्रिंट/PDF के लिए खुलेगा, बस सेव नहीं होगा।
- हर बिल खोलते ही URL में `?id=...` जुड़ जाता है — यही लिंक सीधे भेजकर किसी और को वही बिल भी दिखाया जा सकता है (अगर वे उसी GitHub Pages साइट पर आते हैं)।
